What's good, Woogi / Inoue here again.

This one's short. All of this was supposed to go out with the big update, but it was way too buggy at the time, or I simply forgot to commit and then push it.Anyway, here it is.

## New

- **Templates for everything.** Making a new move, ability, item, type or condition works like making a Fakémon now. Give it a name, then start blank or pick an existing one to start from. You can pick a main-game one or one of your own. It copies the numbers, flags, colours and matchups, depending on what you're making.
- **Code turns into blocks.** When you use something as a template, its Showdown code gets translated into coding blocks you can actually read and change. A 30% burn or a drain becomes its own block. Some main-game stuff has logic that's too weird for a normal block, so that part stays as a "Showdown code" block in the same spot, and the template still does what the original does.
- **Block presets.** The block editor has a Presets button now. Pick an existing move, ability, item or condition and its blocks land on your board as a starting point.
- **Multi-hit moves.** There's a Multi-hit check box under Base Power on custom moves. Set the hit range, then pick Normal or Like Triple Axel, where the power goes up with each hit. You can also make every hit check accuracy, and it stops at the first miss. It tells you exactly what the move will do, like "Power by hit: 20, 40, 60".
- **Pick what a custom move hits.** One foe, itself, everyone next to it, the whole field and so on.
- **Two-factor sign-in.** Settings > Account > Two-factor sign-in. Use an authenticator app or get a code by email.
- **My reports are real tickets now.** When you send feedback or a bug report, it opens a thread. You can read our replies and answer them, and you get a notification when we reply.

## Changes

- **Our own icons.** HeroIcons (the Icon pack this site is using) doesn't have everything, so I drew the missing ones in the same style. The dice are actual dice now, Battle has two crossed swords instead of a flame, and terrain, weather, skulls, paws and a bunch of others finally look like what they are.
- **The move, ability, item, type and condition windows match now.** Same layout on all five, and the title and the save buttons stay in view while you scroll. Flags on custom moves fold away, since that list was huge.
- **The New Fakémon window got the same new look.**

## Fixes

- An accuracy of 0 on a custom move now means it never misses. It used to quietly turn into 100.
- Custom moves exported to Showdown had Protect, Magic Coat and Snatch backwards. A move that could be blocked came out as one that couldn't.
- "Calculating a move's damage" blocks had attacking and defending swapped in the Showdown export.
- Hand-written code with a `condition` in it lost parts of it in the Showdown export.
- The code preview in the block editor showed the wrong thing for moves and items.
