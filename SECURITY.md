# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open a private report: [Report a vulnerability](https://github.com/woogi999/Woogidex/security/advisories/new).
2. If you cannot use GitHub, send an email to **earl@woogi.xyz**.

Give the steps to reproduce the problem, the address or file it affects, and what an attacker can do with it.

## What to expect

- I answer within 7 days.
- I tell you when the fix is live.
- I give you credit in the release notes, if you want it.

## Scope

- `woogidex.com`, `api.woogidex.com` and `dex.woogi.xyz`
- The code in this repository

Out of scope: denial of service, spam, social engineering, and reports from automatic scanners with no proof of impact.

## Safe testing

- Use your own accounts only.
- Do not read, change or delete the data of other people.
- Stop and report as soon as you see data that is not yours.

The machine-readable contact file is at [/.well-known/security.txt](https://woogidex.com/.well-known/security.txt).
